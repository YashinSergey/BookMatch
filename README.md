# BookMatch

Система рекомендаций книг на Goodbooks-10k. Четыре базовые модели, взвешенный гибрид, регулировка разнообразия и нейросетевой ранжировщик.

## Результаты

Test: 30 190 пользователей с релевантной книгой. Настройки зафиксированы до оценки на test.

| Модель | Precision@10 | Recall@10 | nDCG@10 | Разнообразие@10 | Охват, % |
|---|---:|---:|---:|---:|---:|
| Popularity | 0,00015 | 0,0015 | 0,000759 | 0,6182 | 0,18 |
| Content-Based | 0,01727 | 0,1727 | 0,104336 | 0,6023 | 93,71 |
| ItemCF | 0,02527 | 0,2527 | 0,166008 | 0,7107 | 96,22 |
| SVD | 0,00013 | 0,0013 | 0,000611 | 0,6875 | 0,37 |
| Hybrid | 0,02550 | 0,2550 | 0,167040 | 0,6876 | 97,10 |
| Hybrid + MMR | 0,02610 | 0,2610 | 0,170527 | 0,7547 | 97,33 |
| Neural hybrid | 0,02683 | 0,2683 | 0,175973 | 0,7390 | 92,17 |

Нейросетевой гибрид выбран по validation. На test его nDCG@10 составляет 0,175973 против 0,166008 у ItemCF. Дополнительные признаки повышают nDCG@10 отдельного MLP с 0,166219 до 0,173557.

ItemCF остаётся лучшей базовой моделью. Content-Based уступает ему по точности, но может сравнивать книги без истории их оценок.

Гибрид с MMR обеспечивает разнообразие 0,7547 и охват 97,33%. У нейросетевого гибрида эти показатели составляют 0,7390 и 92,17%. Групповой подбор весов улучшения не дал, в обеих группах выбраны одинаковые веса. У коротких историй nDCG@10 нейросетевого гибрида составляет 0,160205 против 0,147168 у MMR. У активных пользователей разница меньше: 0,185967 против 0,185333.

RMSE по всем 45 054 тестовым оценкам: Popularity 0,9441, ItemCF 0,9733, SVD 0,8679. Content-Based, гибриды и MLP не предсказывают рейтинг, поэтому RMSE для них не рассчитывается.

SVD точнее предсказывает оценки, но плохо ранжирует книги. В диагностике отключение факторов сохранило 85,6% Top-10 и те же 40 попаданий. Порядок в основном задаётся смещениями книг. Смещение пользователя может снижать RMSE, но не меняет порядок книг. [Диагностика SVD](reports/svd_diagnostics.csv), [совпадение рекомендаций](reports/svd_overlap.csv).

[Все метрики и группы на test](reports/final_test.csv), [RMSE](reports/final_rmse.csv). Графики и сравнение компонентов сохранены в [Hybrid.ipynb](Notebooks/Hybrid.ipynb).

## Данные

В `data/archive/` нужны четыре CSV из [Goodbooks-10k](https://www.kaggle.com/datasets/zygmunt/goodbooks-10k):

| Файл | Основные поля |
|---|---|
| books.csv | id, book_id, title, original_title, authors |
| ratings.csv | user_id, book_id, rating |
| tags.csv | tag_id, tag_name |
| book_tags.csv | goodreads_book_id, tag_id, count |

Использована версия с 981 756 оценками. В каталоге `id` обозначает локальный ID, `book_id` обозначает ID Goodreads. После загрузки они переименованы в `book_id` и `goodreads_book_id`. Методы рекомендаций возвращают локальные ID.

После удаления дублей и конфликтных пар осталось 978 845 оценок, 53 417 пользователей и 10 000 книг. Данные не входят в репозиторий.

## Модели

- Popularity ранжирует книги по средней оценке train с порогом числа оценок
- Content-Based использует TF-IDF названий и тегов, профиль строится по понравившимся книгам
- ItemCF использует сходство книг по совместным оценкам
- SVD обучает факторы пользователей и книг через Surprise
- Hybrid объединяет до 100 кандидатов каждой модели, исключает прочитанное и нормализует оценки в [0, 1]. Веса: ItemCF 0,75, Content 0,15, SVD 0,10, Popularity 0
- MMR с коэффициентом 0,2 снижает балл книг, похожих на уже выбранные
- MLP получает 4 оценки моделей и 27 признаков: статистики пользователей и книг, теги, сходство с историей. Скрытые слои: 32 и 16 нейронов, обучение: 20 эпох. Нейросетевой гибрид смешивает MLP и Hybrid с весами 0,75 и 0,25

Без истории используется Popularity. Для известных пользователей выделены группы с 1-5 и более 5 оценками в train.

## Оценка

Разбиение случайное, seed 42. У пользователей с тремя и более оценками отложено по одной в validation и test. Остальные оценки входят в train. Истории с 1-2 оценками целиком остаются в train.

На 3 000 пользователях validation подбираются веса и разнообразие. Остальные 27 243 используются для сравнения. Test из первой работы сохранён, параметры гибридов по нему не подбирались.

MLP обучается на внутреннем разбиении train. Целевые оценки исключены до расчёта признаков и обучения базовых моделей. Неоценённые кандидаты служат условно отрицательными примерами.

Релевантна оценка от 4. При одной релевантной книге Recall@K равен доле попаданий, максимум Precision@10 составляет 0,1. Разнообразие измеряется средним 1 - cosine между TF-IDF векторами книг списка, охват измеряется долей каталога в рекомендациях. У базовых моделей кандидаты составляют весь непрочитанный каталог, у гибридов используется объединённый пул.

## Запуск

Проверено на Python 3.13.1. Из корня проекта:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m src.pipeline
```

Запуск выполняет подготовку данных, обучение, подбор, рекомендации и оценку на test. В `reports/pipeline/` сохраняются CSV, `recommendations.csv` и выполненный `Hybrid.ipynb`. Старые отчёты для запуска не нужны.

Другие данные и пользователь:

```bash
python -m src.pipeline --data data/new --output reports/new --user-id 123
```

Формат CSV должен совпадать с описанным выше. Без `--user-id` берётся первый пользователь выборки подбора. Каждый запуск обучает модели заново. Параметры базовых моделей зафиксированы в `hybrid.json`, веса гибрида подбираются на переданных данных.

Для работы с ноутбуками: `python -m jupyterlab`. Отдельное сравнение базовых моделей: `python -m src.experiment`.

## Ограничения

Пул кандидатов покрывает 52,57% релевантных книг test.

Разреженность составляет около 99,82%. Выгрузка ограничивает число оценок книги примерно сотней, что искажает популярность. Дат событий нет, поэтому случайное разбиение не оценивает рекомендации будущих взаимодействий. Качество для полностью новых пользователей и книг отдельно не измерялось.
